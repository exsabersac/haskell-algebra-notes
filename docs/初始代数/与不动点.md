# 初始代数与不动点之间的关系

关系可以收成两句：**有初始代数 ⇒ 其载体一定是函子的不动点（Lambek）；是不动点 ⇏ 就是初始代数**，还差一条万有性质（唯一的 `cata`）。

## 1. 不动点是什么

对象 \(A\) 叫自函子 \(F\) 的 **不动点**，是指存在同构

\[
A \cong F A
\]

也就是：有一对互逆的箭头 \(F A \xrightarrow{\alpha} A\)、\(A \xrightarrow{\alpha^{-1}} F A\)。  
此时 \((A, \alpha)\) 自动是一个 \(F\)-代数，而且结构映射还是同构。

Haskell 直觉：`Fix f` 满足 `Fix f ≅ f (Fix f)`，正是用类型等式写下的不动点。

## 2. 初始代数 ⇒ 不动点（Lambek 引理）

设 \((\mu F, \mathrm{in})\) 是初始 \(F\)-代数，\(\mathrm{in} : F(\mu F) \to \mu F\)。

Lambek 引理说：\(\mathrm{in}\) **必为同构**。因此

\[
\mu F \cong F(\mu F)
\]

载体 \(\mu F\) 一定是 \(F\) 的不动点；初始代数不是「随便一个代数」，而是「带规范同构结构的那个特殊不动点」。

证明想法：因为初始，存在唯一同态 \(h = \operatorname{cata}(F\,\mathrm{in}) : \mu F \to F(\mu F)\)。再验证 \(h\) 是 \(\mathrm{in}\) 的逆（用初始性比较两条回到 \(\mu F\) 的同态，证明它们等于 \(\mathrm{id}\)）。于是 \(\mathrm{in}\) 可逆。

## 3. 不动点 ⇏ 初始代数

任意同构 \(\alpha : F A \xrightarrow{\sim} A\) 都给出代数 \((A, \alpha)\)，载体也是不动点，但一般**没有**「到任意代数恰有一条同态」。

典型反差：

- **有限列表** \([E]\)：初始代数，也是「最小」不动点。
- **有限或无限列表**（或某些域上更大的解）：也可以满足 \(A \cong 1 + E \times A\)，但是更大的不动点；从它们出发到「求和」「拼字符串」等代数，同态不必存在或不必唯一，因此不是初始的。

```text
不动点：     只要求 A ≅ F A
初始代数：   A ≅ F A，且 (A, in) 在 F-代数范畴里初始
```

初始性严格强于「是不动点」。

## 4. 「最小不动点」何时对上初始代数

在许多「计算友好」的设定里（例如 Set 上的多项式／有限分支函子、或 CPO / 域上的连续函子），人们还谈序或逼近意义下的 **最小不动点** \(\mathrm{lfp}(F)\)：

- 从空／底出发迭代 \(F\)，取最小解；
- 这个最小不动点常常**就是**初始代数的载体 \(\mu F\)。

于是口语里会说「递归类型 = 最小不动点 = 初始代数」。严格写法应是：

```text
初始代数的载体 ≅（在合适范畴里的）最小不动点
结构映射 in 是该同构的「封包」方向
```

对偶地：**终余代数**的载体常对应 **最大不动点** \(\nu F\)（无限流、余递归）。同一方程 \(X \cong F X\) 可以有最小解与最大解；初始代数吃最小侧，终余代数吃最大侧。

## 5. 对照表

| 概念 | 要求 | 典型 Haskell |
|------|------|----------------|
| \(F\)-代数 | \(\varphi : F A \to A\)（不必可逆） | `f a -> a` |
| 不动点 | \(A \cong F A\) | `Fix f ≅ f (Fix f)` |
| 初始代数 | 不动点 + 到任意代数有唯一同态 | `Fix f` + `cata` |
| 最小不动点 | 逼近／序意义下最小的解 | 有限数据结构 |
| 终余代数／最大不动点 | 对偶的万有性质 | `Stream`、`ana` |

## 6. 一句话

**初始代数提供不动点；不动点不必是初始代数。**  
Lambek 保证「初始 ⇒ 同构不动点」；万有性质（唯一 `cata`）保证「在所有不动点／所有代数里，它是那个可被唯一折叠的最小／最自由的那个」。
