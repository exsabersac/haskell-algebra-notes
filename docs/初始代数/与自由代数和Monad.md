# 初始代数、自由代数与 Monad

不完全是「初始代数 = free algebra，monad 只是其应用」。更准确的说法是：

**初始代数是「自由代数」在生成元为空时的特例；自由 monad 把「随生成元变化的自由代数」打成一个 monad。但一般的 monad 比这更宽，不是初始代数概念的下属应用。**

## 1. 公式层面（造载体的方式相同）

```text
μF            =  μY.  F Y           -- Fix f：递归 ADT
Free_F(X)     =  μY.  X + F Y       -- Free f a：带生成元的自由 F-代数
```

同一台机器（取初始代数／最小不动点），换了输入函子：

- 左边喂 \(F\)
- 右边喂 \(X + F(-)\)

所以会觉得「只是不动点公式不同」——在**怎么长出那棵树**这一层，的确如此。

## 2. 概念层面（还差的半步）

| | \(\mu F\) | \(\mathrm{Free}_F(X)\) |
|--|-----------|-------------------------|
| 是谁的初始代数 | \(F\) | \(X + F(-)\) |
| 外部生成元 | 无（\(X = 0\)） | 有（叶子可来自 \(X\)，如 `Pure a`） |
| 随 \(X\) 变化 | 单个类型 | 可打包成**自由 monad** |

公式不同，背后是**范畴角色**不同：同态、唯一 `cata`、谁往谁那儿折，比较的对象不一样。不能说「同一个初始代数写了两种式子」。

\(X\) 不是装饰，是生成元：

```haskell
Fix ExprF        -- 整棵表达式，叶只能是 Lit 这类「F 自带」的常量
Free ExprF a     -- 还可以在叶上放任意 a（洞、变量、续计算）
```

## 3. 修正用词：不是「没有载体」

每个代数都有**载体**（carrier）。

- 初始代数的载体是 \(\mu F\)
- 自由代数 \(\mathrm{Free}_F(X)\) 的载体是 \(\mu Y.(X + F Y)\)

正确记忆句：

> **初始代数 = 无外部生成元的自由代数；其载体就是单纯由 \(F\) 长出的递归结构 \(\mu F\)。**

不是「没有载体的自由代数」——载体还在，就是那棵纯语法树类型本身。  
`Lit Int` 那种叶子是 **\(F\) 签名里就有的常量构造器**，不算「外部生成元 \(X\)」。外部生成元指公式里多写的那个 \(X+\)，在 `Free` 里就是 `Pure a`。

关系式：

```text
初始 F-代数  =  自由 F-代数（生成元为空）
             =  Free_F(0)  ≅  μF

自由 F-代数（生成元 X）  =  另一个函子 (X+F) 的初始代数
```

## 4. Monad 站在哪一层

### （A）自由 monad —— 紧贴自由代数

函子 \(F\) 的**自由 monad** 把每个对象 \(X\) 送到 \(\mathrm{Free}_F(X)\)，并带上自然的 `return` / `join`。  
Haskell 的 `Free f` 就是这件事。

```text
自由代数（随 X 变） ──打包──▶ 自由 monad Free F
```

「`Free f` 的 monad 代数 ≅ `f` 的 F-代数」也落在这条线上。

### （B）一般的 monad —— 不只是初始代数的应用

任意伴随 \(L \dashv R\) 都诱导 monad \(T = RL\)。例如：

- 列表 monad ← 自由 monoid 伴随（Set ⇄ Mon）
- 状态、读写、延续等 ← 别的伴随或直接给出的 \(T\)
- 许多 monad **不能**写成「某个端函子 \(F\) 的 `Free f`」

对一般 monad \(T\)，人们谈的是 **Eilenberg–Moore 代数** \(T A \to A\)（如 `[]` 的代数 = monoid）。  
\(T A\)（带 `join`）是**自由 \(T\)-代数**（生成元为 \(A\)），这是相对遗忘函子 \(\mathrm{EM}(T) \to \mathcal{C}\) 的自由，不再等于「\(F\) 的初始代数」那一套，除非 \(T\) 恰好是自由 monad 等特殊情形。

```text
初始代数 / 自由 F-代数 / Free f
        ⊆  与函子 F 相关的故事

一般 monad + EM 代数
        ⊇  远大于 Free；列表、Maybe、State…
```

## 5. 最小对照表

```text
F-代数范畴的初始对象          →  μF           （递归 ADT / Fix f）
X+F 的初始对象                →  Free_F(X)    （自由 F-代数）
X ↦ Free_F(X) 做成的 monad    →  Free F       （自由 monad）
任意 monad T 的自由代数 on X  →  (T X, join)  （EM 意义下的自由）
任意 monad T 的全部代数       →  EM(T)        （如 [] ↦ Monoid）
```

## 6. 直接回答常见误解

**「初始代数就是 free algebra？」**  
—— 只在「生成元为空」或「把自由代数说成 \(X+F\) 的初始代数」时成立。日常说的 free algebra 多半带生成元 \(X\)，应写成 \(\mu Y.(X+FY)\)，不等于 \(\mu F\)。

**「monad 只是其一个应用？」**  
—— 对 **自由 monad** 大致对：它是自由 \(F\)-代数的统一包装。  
对 **monad 整体** 不对：monad 与 EM 代数是平行、更广的一层。

**「两个只是不动点公式不同？」**  
—— 造树方式上：对。  
—— 概念位置上：还差初始性相对谁、有没有生成元、能否做成 monad。
