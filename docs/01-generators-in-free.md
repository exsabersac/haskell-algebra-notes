# Free 中的生成元是做什么的？

**生成元**就是 `Free f a` 里那个 `a`：树上允许出现的「外来叶子」。节点形状由函子 `f` 规定；叶子可以来自这批生成元，而不必是 `f` 签名里写死的常量。

## 在类型里长什么样

```haskell
data Free f a
  = Pure a                 -- 一片生成元叶子
  | Free (f (Free f a))    -- 按 f 的形状再往下长
```

- `f`：运算／效果／构造器的**形状**（怎么分支、带什么参数）
- `a`：生成元类型——你可以塞进树里的**原子值**（变量、洞、最终结果、下一步计算的种子）

没有生成元时（\(X = 0\)）就退化成 `Fix f`：叶子只能来自 `f` 自己的常量分支（如 `Lit Int`）。有了 `a`，多出 `Pure`，树可以在任意位置「停在一个外来值上」。

## 生成元的三个常见用途

### 1. 当变量／洞（语法）

```haskell
data ExprF r = AddF r r | NegF r   -- 故意没有 Lit
type Expr a = Free ExprF a

-- Pure "x"           变量 x
-- Free (AddF (Pure "x") (Pure "y"))
```

生成元 = 变量名；解释时用 `a -> 值` 再 `foldFree` 赋值。`Fix ExprF` 做不到「任意变量」，除非把变量写进 `ExprF`。

### 2. 当最终结果／返回值（计算）

```haskell
-- Free ((,) String) Int  ≅  ([String], Int)
Pure 42
Free ("log", Pure 42)
```

生成元 `Int` 是「算完后手里的值」；前面的 `String` 是效果形状。这正是「带日志的纯结果」。

### 3. 当「接下来的程序」接口（与 `>>=` 对接）

`Monad` 的 `>>=` 正是：**在生成元位置继续接计算**。

```haskell
Pure x  >>= k  = k x
-- 把叶子上的生成元换成 k 给出的新子树
```

所以生成元不只是「树叶装饰」，而是自由 monad 能组合的原因：叶子类型 `a` 表示「这里还缺一个 `a`，交给后面的绑定去填」。

## 和「载体」不要混

| 词 | 指什么 |
|----|--------|
| 生成元类型 `a` | 允许出现的叶子种类（`Pure` 的参数） |
| 载体（某个代数的） | 解释完成后落进去的类型，如 `foldFree φ :: Free f b -> b` 里的 `b` |

同一棵 `Free f a` 树，生成元是 `a`；你选代数 `φ :: f b -> b` 并先把 `a -> b` 映过去之后，载体才是 `b`。

## 一句话

**生成元 = 自由代数里「由外部提供的原子」；在 `Free` 里就是 `Pure a` 的 `a`。**  
有了它们，树才能表示变量、返回值或 `>>=` 的接缝；去掉它们（空生成元）就只剩单纯递归 ADT `μf`。
