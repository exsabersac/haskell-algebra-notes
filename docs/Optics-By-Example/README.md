# Optics By Example — 各章中文要点摘要

《Optics By Example》（Chris Penner）是一本以 Haskell `lens` 库为例、偏实践的 optics 教程。全书按 Lens → Fold → Traversal → Prism → Iso 等主线递进，强调可组合的双向数据变换、运算符与常见数据结构 / JSON / Monad 场景。本书为早期访问、仍在完善；末尾有练习答案与若干计划中的章节。

本目录是**读书要点摘要**（非全文翻译）：正文用清晰简体中文，术语保留英文（Lens、Prism、Traversal、Iso 等）。

可运行的 Lens / van Laarhoven / Strong / Tambara 演示与本仓教程对照，见独立仓库 [tambara-lens-demo](https://github.com/exsabersac/tambara-lens-demo)。
