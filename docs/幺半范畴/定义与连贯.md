# 幺半范畴：定义与连贯

幺半范畴（monoidal category）把「带单位的结合积」提升到范畴层面：对象之间有张量 \(\otimes\)，还有单位对象 \(I\)，以及把结合律／单位律写成**自然同构**的一组连贯子（coherence morphisms）。

## 1. 数据 \((\mathcal{C},\otimes,I,\alpha,\lambda,\rho)\)

一个（非严格）幺半范畴包含：

| 部件 | 类型 | 作用 |
|------|------|------|
| \(\mathcal{C}\) | 范畴 | 对象与箭头 |
| \(\otimes\) | \(\mathcal{C}\times\mathcal{C}\to\mathcal{C}\) | 张量（双函子） |
| \(I\) | 对象 | 单位对象 |
| \(\alpha\) | \((A\otimes B)\otimes C \xrightarrow{\sim} A\otimes(B\otimes C)\) | 结合子（associator） |
| \(\lambda\) | \(I\otimes A \xrightarrow{\sim} A\) | 左单位子（left unitor） |
| \(\rho\) | \(A\otimes I \xrightarrow{\sim} A\) | 右单位子（right unitor） |

\(\alpha,\lambda,\rho\) 都是**自然同构**，不是「等式级」的恒等（除非进入严格情形）。

## 2. 连贯直觉

任意用 \(\otimes\)、括号和 \(I\) 写出的两种「显然该相等」的复合方式，应通过 \(\alpha,\lambda,\rho\) 的复合给出**同一条**同构。经典图画是五边形（结合）与三角形（单位）；Mac Lane 连贯定理保证：只要这几张基本图交换，所有由连贯子搭出的图都交换。

实用读法：写证明时可以「假装结合律严格成立」，最后靠连贯定理保证没漏同构。

## 3. 严格 vs 非严格

- **严格（strict）**：\((A\otimes B)\otimes C = A\otimes(B\otimes C)\)，\(I\otimes A = A = A\otimes I\)，且 \(\alpha,\lambda,\rho\) 都是恒等。
- **非严格**：只有同构，对象层面括号与单位不能随便擦掉。

多数自然例子（\(\mathbf{Set}\) 的笛卡尔积、\(R\)-模的张量积、端函子复合）是非严格的；严格例子更像「人为收紧」后的骨架。

## 4. Mac Lane 严格化（一句）

**Mac Lane 严格化定理**：任意幺半范畴都等价于一个严格幺半范畴（作为幺半范畴等价）。因此「严格地算」在等价意义下总是合法的；细节同构仍在，只是可被推到等价的另一侧。

## 5. 对称（可选一句）

若还要规范的交换同构 \(\sigma_{A,B}: A\otimes B \xrightarrow{\sim} B\otimes A\)，且与 \(\alpha,\lambda,\rho\) 连贯，则得到**对称幺半范畴**（symmetric monoidal）。笛卡尔积、向量空间张量积常带对称；端函子的 \(\circ\) **一般不对称**（\(F\circ G \not\simeq G\circ F\)）。

## 一句话

幺半范畴 = 范畴 + 张量 + 单位 + 把结合／单位写成自然同构的连贯子；严格化定理允许在等价意义下当结合律是等式来用。
