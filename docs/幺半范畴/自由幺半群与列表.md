# 自由幺半群是列表

在 \((\mathbf{Set},\times,1)\) 里，由集合 \(X\) 生成的**自由 monoid**（free monoid）就是列表 \([X]\)，运算为拼接 `++`，单位为 `[]`。  
术语保留精确英文：free monoid、UP（universal property）、ListF、foldMap、EM、Free。

相关：[例子与Monad.md](例子与Monad.md) · [自由幺半群与ListF代数](自由幺半群与ListF代数.md) · [List的EM代数与Monoid](List的EM代数与Monoid.md) · [自由单子](自由单子.md) · [自由函子与自由代数](../Free/自由函子与自由代数.md) · [常见组合](../函子组合/常见组合.md) · [`FunctorCombo/Demo.hs`](../../src/FunctorCombo/Demo.hs) · [`FreeDemo/Demo.hs`](../../src/FreeDemo/Demo.hs)

## 1. \(\mathrm{FreeMon}(X) \cong [X]\)

Ambient：\((\mathbf{Set},\times,1)\)。遗忘 \(U:\mathbf{Mon}\to\mathbf{Set}\)，左伴随给出自由 monoid：

\[
\mathrm{FreeMon}(X) \;\cong\; [X]
\]

| 结构 | 列表上的实现 |
|------|----------------|
| 载体 | 有限列表 \([X]\) |
| 乘法 \(\mu\) | `(++)` |
| 单位 \(\eta_I\) | `[]` |
| 生成元嵌入 | \(\eta : X \to [X]\)，\(\eta\,x = [x]\) |

`[]` 是 monoid 单位，来自签名里的 \(1\)（空列表构造器），**不是**外部生成元 \(X\) 的一员。生成元只通过单例列表 \(\eta\,x = [x]\) 进入。

---

## 2. UP：任意 \(f:X\to M\) 唯一扩展为 monoid 同态

设 \(M\) 为 monoid（`Monoid m`）。任意函数 \(f : X \to M\) 唯一扩展为 monoid 同态 \(\varphi : [X] \to M\)，使

\[
\varphi \circ \eta = f
\]

即 \(\varphi([x]) = f\,x\)。在 Haskell 里这个 \(\varphi\) 就是 `foldMap f`：

```haskell
-- φ = foldMap f
foldMap :: Monoid m => (x -> m) -> [x] -> m
foldMap f []     = mempty
foldMap f (x:xs) = f x <> foldMap f xs
```

定律（monoid 同态）：

```text
φ []          = mempty
φ (xs ++ ys)  = φ xs <> φ ys
```

UP 说：满足 \(\varphi\circ\eta=f\) 的 monoid 同态只有这一个。

## 3. 初始代数视角：`ListF` 与 \(\mu\)

一层形状：

```haskell
data ListF x r = NilF | ConsF x r
-- ListF x r  ≅  1 + x × r
```

最小不动点／初始代数：

\[
\mu(\mathrm{ListF}\,x) \;\cong\; [x]
\]

折叠即 catamorphism；与 `foldr` 同型：

```haskell
-- cata / foldr' 草图（base-only）
cataList :: (ListF x a -> a) -> [x] -> a
cataList φ []     = φ NilF
cataList φ (x:xs) = φ (ConsF x (cataList φ xs))

-- 与 foldr 对齐的直觉
-- foldr c n ≡ cata (λ NilF → n; λ ConsF x r → c x r)
```

可运行草图见 [`src/FunctorCombo/Demo.hs`](../../src/FunctorCombo/Demo.hs)（`ListF`、`listToFix` / `listFromFix`、`cata`）；公式表见 [常见组合](../函子组合/常见组合.md)（\(\mu Y.\,1+e\times Y \to [e]\)）；ADT＝初始代数见 [与递归ADT](../初始代数/与递归ADT.md)。

自由 monoid 的乘法／单位与「`ListF` 初始代数」是同一载体上的两副眼镜：UP／`foldMap` 谈 monoid 同态；`cata` 谈对一层 `NilF`/`ConsF` 的解释。

**概念上仍是两套定义**（分属 \(\mathbf{Mon}\) 与 \(\mathrm{Alg}(\mathrm{ListF}\,X)\)）；仅对此 \(F\cong 1+X\times(-)\) 载体重合。桥接等式：

```haskell
-- foldMap f ≡ cataList (fromMonoid f)
```

`fromMonoid`、逆向是否总成立、UP 双射 \(\Phi/\Psi\) 的细节见专题 [自由幺半群与ListF代数](自由幺半群与ListF代数.md)。换 \(F\)（如 \(\mu Y.1+Y\cong\mathbb{N}\)、`Free f a`）则两套故事拆开。

## 4. 生成元是单例；`[]` 不是来自 \(X\)

| | 来源 | 角色 |
|--|------|------|
| \(\eta\,x = [x]\) | 外部生成元 \(X\) | 把字母嵌进自由 monoid |
| `[]` | 签名里的 \(1\)（`NilF`） | monoid 单位；无外部生成元参与 |

不要说「空列表也是生成元」：生成元集合是 \(X\)；单位来自 monoid 结构（及 `ListF` 的 `Nil` 分支）。

---

## 5. 对照：自由 monoid vs `Free f a`／自由 monad

| | 自由 monoid \(\mathrm{FreeMon}(X)\) | `Free f a`／自由 monad |
|--|--------------------------------------|-------------------------|
| Ambient | \((\mathbf{Set},\times,1)\) | \((\mathrm{End},\circ,\mathrm{Id})\) |
| 输入 | 集合 \(X\) | 自函子 \(f\)（及生成元 \(a\)） |
| 产物 | \([X]\)，运算 `++` / `[]` | `Free f a`；整族 `Free f` 配 `Pure`/`join` |
| 折叠 | `foldMap`（进任意 monoid） | `foldFree`（进任意 \(f\)-代数／EM） |
| 另一视角 | \(\mu Y.\,1+X\times Y\) | \(\mu Y.\,a+f\,Y\)；End 里自由 monoid-对象 |

同一句「自由 monoid-对象」口号；张量从 \(\times\) 换成 \(\circ\)，输入从集合换成端函子。详见 [自由单子](自由单子.md) · [自由函子与自由代数](../Free/自由函子与自由代数.md)。

## 6. 短例：`foldMap`

```haskell
import Data.Monoid (Sum(..), Product(..))

foldMap Sum     [1,2,3]  -- Sum 6
foldMap Product [1,2,3]  -- Product 6
foldMap (:[])   "ab"     -- ["a","b"]   -- η 的列表形式；此处 m = []
```

`foldMap (:[])` 是 \(\eta\) 方向上的「逐元素装箱」；一般 \(f\) 则把每个字母送进目标 monoid 再 `<>` 起来。

## 7. 易混三点

### （1）`[X]` 是自由 monoid ≠ `[]` 的 EM 代数是 `Monoid`

| | 自由 monoid on \(X\) | `[]` 的 EM 代数 |
|--|----------------------|-----------------|
| 在说什么 | 由 \(X\) **生成**的那个 monoid（载体 \([X]\)） | 哪些载体 \(A\) 配上 \(\alpha:[A]\to A\) 合法消去列表 monad |
| 典型映射 | `foldMap f :: [X] -> M` | `mconcat :: Monoid a => [a] -> a` |
| 结论 | \([X]\) **是**自由 monoid | `[]` 的 EM 代数 **≅** `Monoid` |

前者谈「谁是自由对象」；后者谈「列表 monad 的代数是什么」。展开（定义、双射、与 ListF 对照、Kleisli 边界）见 [List的EM代数与Monoid](List的EM代数与Monoid.md)。

### （2）`Free ((,) e) a ≅ ([e], a)` 不是同一句

那是**自由 \(f\)-代数**故事：\(f = ((,)\,e)\)，载体同构于「日志列表 + 种子 \(a\)」。折叠是逐步更新 \(\varphi:(e,a)\to a\)，**不**要求 \(a\) 为 monoid，也**不是**「\(e\) 的自由 monoid」这句在 Set 里的 UP。演示见 [`src/FreeDemo/Demo.hs`](../../src/FreeDemo/Demo.hs)；根 README 第 3 节故事 A/B 对照。

### （3）无限流 \(\nu\) ≠ 自由 monoid

```text
μ Y. 1 + e × Y   →  有限列表 [e]   （自由 monoid；初始代数）
ν Y. e × Y       →  流 Stream e    （终余代数；无「空」、可无限）
```

自由 monoid 只要**有限**字；流是最大不动点侧，不是 \(\mathrm{FreeMon}(e)\)。

## 8. 收束图

```text
X ──η=[(-)]──▶ [X] ──foldMap f──▶ M   (M monoid；φ 唯一)
                  │
                  │ ≅ μ(ListF X) ≅ Fix (ListF X)
                  ▼
            NilF | ConsF    （cata / foldr'）
```

### 已澄清结论

1. 在 \((\mathbf{Set},\times,1)\) 中 \(\mathrm{FreeMon}(X)\cong[X]\)，乘法 `++`，单位 `[]`。
2. UP：\(f:X\to M\) 唯一扩展为 monoid 同态 \(\varphi=\mathrm{foldMap}\,f\)；\(\varphi[]=\mathrm{mempty}\)，\(\varphi(xs{++}ys)=\varphi xs\langle\rangle\varphi ys\)。
3. \([x]\cong\mu(\mathrm{ListF}\,x)\)，`ListF x r\cong 1+x\times r`；与 FunctorCombo demo、常见组合、递归 ADT 笔记一致。
4. 生成元是单例 \(\eta\)；`[]` 来自签名中的 \(1\)，不是外部生成元 \(X\)。
5. 自由 monoid 与 `Free`／自由 monad 是同一 pattern、不同 ambient（Set vs End；`foldMap` vs `foldFree`）。

### 易混点

| 易混 | 澄清 |
|------|------|
| \([X]\) 自由 monoid vs `[]` 的 EM＝`Monoid` | 前者是自由对象；后者是列表 monad 的代数范畴（详见 [EM 笔记](List的EM代数与Monoid.md)） |
| `Free ((,) e) a ≅ ([e],a)` | 自由 \(f\)-代数／Writer 形，不是 Set 上「\(e\) 的自由 monoid」同一句 |
| 无限流 \(\nu\) | 终余代数；自由 monoid 只含有限列表 |
