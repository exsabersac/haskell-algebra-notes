# 自由单子是 End 里的自由 monoid-对象

在 \((\mathrm{End},\circ,\mathrm{Id})\) 里，由自函子 \(f\) 生成的**自由 monoid-对象**就是**自由 monad**（free monad）`Free f`：单位为 `Pure`，乘法为 `join`。  
术语保留精确英文：free monad、free \(f\)-algebra、UP、foldFree、foldFreeM、EM、End。

相关：[自由幺半群与列表](自由幺半群与列表.md) · [例子与Monad.md](例子与Monad.md) · [自由函子与自由代数](../Free/自由函子与自由代数.md) · [Fix编码](../Free/Fix编码.md) · [foldFree与cata](../Free/foldFree与cata.md) · [与自由代数和Monad](../初始代数/与自由代数和Monad.md) · [`FreeDemo/Demo.hs`](../../src/FreeDemo/Demo.hs)

## 1. 一行对照：自由 monoid vs 自由 monad

| | 自由 monoid | 自由 monad |
|--|-------------|------------|
| Ambient | \((\mathbf{Set},\times,1)\) | \((\mathrm{End},\circ,\mathrm{Id})\) |
| 输入 | 集合 \(X\) | 自函子 \(f\) |
| 产物 | \(([X],{++},[])\) | \((\mathrm{Free}\,f,\,\mathrm{Pure},\,\mathrm{join})\) |
| 载体公式 | \(\mu Y.\,1+X\times Y\) | 对每个 \(a\)：\(\mu Y.\,a+f\,Y\) |

同一句「自由 monoid-对象」；张量从 \(\times\) 换成 \(\circ\)，输入从集合换成端函子。Set 侧展开见 [自由幺半群与列表](自由幺半群与列表.md)。

## 2. 数据：`Free f a` 与整族 `Free f`

```haskell
data Free f a = Pure a | Free (f (Free f a))
-- Free f a  ≅  μX. a + f X  ≅  Fix (Sum (Const a) f)
```

| 说法 | 指什么 |
|------|--------|
| 对象 `Free f a` | 由生成元 \(a\) 生成的**自由 \(f\)-代数**（载体） |
| 整族 `Free f` + `Pure`/`join` | **自由 monad**（End 里 on \(f\) 的自由 monoid-对象） |

```text
Free f a     =  某一个对象（自由 f-代数 on a）
Free f       =  整族 + Pure/join  =  自由 monad
```

编码与 `toFix`/`fromFix` 见 [Fix编码](../Free/Fix编码.md)；对象／族分界见 [自由函子与自由代数](../Free/自由函子与自由代数.md)。

## 3. Monad 结构草图（base-only）

```haskell
-- return = Pure  （η : Id → Free f）
return :: a -> Free f a
return = Pure

-- >>=
(>>=) :: Functor f => Free f a -> (a -> Free f b) -> Free f b
Pure x >>= k = k x
Free t >>= k = Free (fmap (>>= k) t)

-- join  （μ : Free f ∘ Free f → Free f）
join :: Functor f => Free f (Free f a) -> Free f a
join = (>>= id)
-- 或：join (Pure m) = m；join (Free t) = Free (fmap join t)
```

单位／结合律使 `Free f` 成为 End 中的 monoid 对象，即 Monad。口号落点见 [例子与Monad.md](例子与Monad.md)。

## 4. UP 两层

### （A）作为自由 \(f\)-代数：`interpret` / `foldFree` = `cata` for \(a+f\)

任意 \(f\)-代数 \(\varphi : f\,b\to b\) 配上对生成元的解释 \(a\to b\)，唯一决定折叠：

```haskell
-- 生成元与载体同型时的简写
foldFree :: Functor f => (f a -> a) -> Free f a -> a
foldFree φ (Pure x) = x
foldFree φ (Free t) = φ (fmap (foldFree φ) t)

-- 一般：先改叶，再折
interpret :: Functor f => (a -> b) -> (f b -> b) -> Free f a -> b
interpret env φ = foldFree φ . fmap env
```

`foldFree φ = cata`（相对函子 \(a+f(-)\)）。交换图见 [foldFree与cata](../Free/foldFree与cata.md)。

### （B）作为自由 monad：`foldFreeM`

自然变换 \(f \rightsquigarrow m\)（对每个 \(a\)：`f a -> m a`）唯一扩展为 **monad 同态** \(\mathrm{Free}\,f \to m\)：

```haskell
-- 草图：f ~> m  ⇒  唯一 Monad 同态 Free f → m
foldFreeM :: (Functor f, Monad m) => (forall x. f x -> m x) -> Free f a -> m a
foldFreeM _ (Pure x) = return x
foldFreeM η (Free t) = η t >>= foldFreeM η
-- 即：Pure ↦ return；一层 f 用 η，再 join／>>= 接下去
```

（A）谈「进任意 \(f\)-代数」；（B）谈「进任意 monad \(m\)，且保留 `return`/`join`」。二者同一自由性，视角不同。

## 6. 并排：自由 monoid vs 自由 monad

| | 自由 monoid \(\mathrm{FreeMon}(X)\) | 自由 monad \(\mathrm{Free}\,f\) |
|--|--------------------------------------|--------------------------------|
| Ambient | \((\mathbf{Set},\times,1)\) | \((\mathrm{End},\circ,\mathrm{Id})\) |
| 嵌入生成元 | \(\eta : X\to[X]\)，`[x]` | `Pure`；一层 \(f\) 经 `Free` |
| 折叠进「同类」 | `foldMap f` → 任意 monoid | `foldFreeM η` → 任意 monad |
| 折叠进代数 | （monoid 同态即上） | `foldFree` / `interpret` → \(f\)-代数 |
| 不动点视角 | \(\mu Y.\,1+X\times Y\cong[X]\) | \(\mu Y.\,a+f\,Y\cong\mathrm{Free}\,f\,a\) |

记忆：`foldMap` ↔ `foldFree` / `foldFreeM`；列表笔记 §5 已有短表，本页展开 End 侧。

## 7. 易混点

### （1）`Free f a` ≠ 自由 monad

| | `Free f a` | 自由 monad `Free f` |
|--|------------|---------------------|
| 是什么 | 固定 \(a\) 的一棵（类）树；自由 \(f\)-代数载体 | 整族 \(a\mapsto\mathrm{Free}\,f\,a\) + `Pure`/`join` |
| 口号 | 自由 \(f\)-代数 on \(a\) | End 里 on \(f\) 的自由 monoid-对象 |

### （2）自由 monad ≠ 自由 monoid

同一 pattern，不同 ambient：Set 的 \(\times\) vs End 的 \(\circ\)。不要把 `Free f a` 直接叫成「某个集合的自由 monoid」。

### （3）EM 自由代数 \((T a,\mu)\) ≠ \(\mu X.\,a+T X\)

对一般 monad \(T\)，相对 \(\mathrm{EM}(T)\to\mathcal{C}\) 的自由代数 on \(a\) 载体是 \(T a\)（带 `join`），**不是**再写一遍 \(\mu X.\,a+TX\)。后者是「某函子的 `Free`」公式；仅当 \(T\) 恰为自由 monad 等特殊情形才对上。见 [与自由代数和Monad](../初始代数/与自由代数和Monad.md)、[自由函子与自由代数](../Free/自由函子与自由代数.md)。

### （4）存在性／大小（DaoFP 风格提醒）

遗忘「End 里的 monoid 对象 → 底层端函子」**未必**有左伴随；一般 \(f\) 上「自由 monad」不必在严格伴随意义下存在。实践里 `Free` 常**直接用不动点／递归类型**定义（`μX. a+fX`），并在 \(f\) 足够好（如多项式）时当作自由 monad 使用。本笔记以该构造与 UP 草图为准，不声称任意 \(\mathrm{End}\) 上都有伴随。

### （5）`Free Identity` 等

`Free Identity`、`Free Maybe`、`Free ((,) e)` 是**不同**的自由 monad（换 \(f\) 即换一层形状）。`Free Identity a` 是链状包装，**不是** `Identity a`；`Free ((,) e) a ≅ ([e],a)` 已见上例，勿与「\(e\) 的自由 monoid」或「`[]` 的 EM＝`Monoid`」混句。

## 8. 收束图

```text
f ──自由 monoid-对象──▶ Free f  (= Pure / join；End 里)
         │
         │  对每个 a
         ▼
   Free f a  ≅  μ(a + f)  ≅  Fix (Sum (Const a) f)
         │
         ├─ foldFree / interpret ──▶ 任意 f-代数   （自由 f-代数 UP）
         └─ foldFreeM (f ~> m)  ──▶ 任意 monad m （唯一 monad 同态）
```

对照 Set：

```text
X ──η──▶ [X] ──foldMap──▶ M     （自由 monoid）
f ──η──▶ Free f ──foldFreeM──▶ m （自由 monad）
```

### 已澄清结论

1. 在 \((\mathrm{End},\circ,\mathrm{Id})\) 中，自由 monad = 由 \(f\) 生成的自由 monoid-对象；与 Set 上 \(\mathrm{FreeMon}(X)\cong[X]\) 同一 pattern。
2. `Free f a ≅ μX. a+fX ≅ Fix(Sum (Const a) f)` = 自由 \(f\)-代数载体；整族 + `Pure`/`join` 才是自由 monad。
3. UP：（A）`foldFree`/`interpret` = 对 \(a+f\) 的 `cata`；（B）`f~>m` 唯一扩展为 monad 同态 `foldFreeM`。
4. `LogF e`、`ExprF`/`evalWith` 演示见 FreeDemo；前者 ≅ `([e],a)`，是自由 \(f\)-代数，非 Set 自由 monoid 句。
5. `foldMap` ↔ `foldFree`/`foldFreeM`；EM 自由代数 \((Ta,\mu)\) 与 \(\mu X.a+TX\) 勿混；存在性常经不动点定义而非一律伴随。

### 易混点

| 易混 | 澄清 |
|------|------|
| `Free f a` vs 自由 monad | 对象 vs 整族+`Pure`/`join` |
| 自由 monad vs 自由 monoid | End vs Set；`∘` vs `×` |
| EM 自由 \((Ta,\mu)\) vs \(\mu X.a+TX\) | 一般 monad 的自由代数载体是 \(Ta\) |
| 伴随必存在 | End 上遗忘未必有左伴随；`Free` 常用 fixpoint |
| `Free Identity` / `Free ((,) e)` | 换 \(f\) 换形状；后例 ≅ `([e],a)`，非「\(e\) 的自由 monoid」 |
