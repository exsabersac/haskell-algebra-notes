# 余密度单子（Codensity monad）

澄清 \(T^G:=\mathrm{Ran}_G(G)\) 是 \(\mathcal{C}\) 上的**单子**（monad），以及它与伴随诱导单子 \(R\circ L\)、与 continuation monad \(\mathrm{Cont}\) 的分界。  
术语保留精确英文：Ran、Lan、UP、end、codensity、Cont、Nat。

相关：[定义与UP](定义与UP.md) · [左伴随作为右Kan](左伴随作为右Kan.md) · [例子与Monad](../幺半范畴/例子与Monad.md)

---

## 1. 定义

对函子 \(G:\mathcal{D}\to\mathcal{C}\)，若右 Kan 扩展存在，定义

\[
T^G \;:=\; \mathrm{Ran}_G(G):\mathcal{C}\to\mathcal{C}
\]

这是 \(\mathcal{C}\) 上的自函子，且带有规范的 monad 结构，称为 \(G\) 的**余密度单子**（codensity monad）。

### UP

\[
\mathrm{Nat}(H,\, T^G)
\;\cong\;
\mathrm{Nat}(H\circ G,\, G)
\]

单位 \(\eta:\mathrm{Id}\Rightarrow T^G\)、乘法 \(\mu:T^G\circ T^G\Rightarrow T^G\) 由该 UP 的**唯一性**唯一确定（把合适的 Nat 对应回去）。

### 点值（end）

\[
T^G(c)
\;=\;
\int_{d}\, \bigl[\mathcal{C}(c,\, Gd),\, Gd\bigr]
\]

### Haskell 草图（语义上仅需 `base`）

```haskell
-- Codensity g c  ≅  forall d. (c -> g d) -> g d
-- 对应 end ∫_d [C(c, g d), g d] 的「点」味道
newtype Codensity g c = Codensity
  { runCodensity :: forall d. (c -> g d) -> g d }
```

（`Functor`／`Monad` 实例可按标准 Codensity 写法补全；本主题不加强制 demo。）

---

## 2. 伴随诱导：\(T^R\cong R\circ L\)

若 \(L\dashv R\)（\(L:\mathcal{C}\to\mathcal{D}\)，\(R:\mathcal{D}\to\mathcal{C}\)），则

\[
T^R \;=\; \mathrm{Ran}_R(R) \;\cong\; R\circ L
\]

即：沿右伴随对**自身** \(R\) 的右 Kan，恢复伴随诱导的 monad \(RL\)。

对偶一句：**密度余单子**（density comonad）\(\mathrm{Lan}_L(L)\cong L\circ R\)。

（与 [左伴随作为右Kan](左伴随作为右Kan.md) 对照：那里是 \(\mathrm{Ran}_R(\mathrm{Id})\cong L\)；这里是 \(\mathrm{Ran}_R(R)\cong RL\)——第二个参数从 \(\mathrm{Id}\) 换成 \(R\)。）

---

## 3. 柯里化示例

取 \(L=A\times-\)、\(R=(-)^A\)（\(\mathbf{Set}\)）。则

\[
RL(X)=(A\times X)^A,\qquad
\eta_X(x)=\lambda a.\,(a,x)
\]

end 写法：

\[
T^R(X)
\;=\;
\int_{Y}\, \bigl[\mathbf{Set}(X,\, Y^A),\, Y^A\bigr]
\;\cong\;
(A\times X)^A
\]

### 元素级链（精神上）

```text
forall Y. (X -> Y^A) -> Y^A
  ≅  forall Y. (A × X -> Y) -> (A -> Y)
  ≅  A -> A × X          -- 再指数伴随／Yoneda 味道回到 (A×X)^A 的元素视角
```

（中间用 \(\mathbf{Set}(X,Y^A)\cong\mathbf{Set}(A\times X,Y)\)；末步是表示／Yoneda 消去。）更干净的对象级结论仍是 \(T^R\cong RL=(-)^A\circ(A\times-)\)。

---

## 4. 易混：\(\mathrm{Cont}_A\) ≠ 整条 \(R\) 的余密度

| \(G\) | \(T^G=\mathrm{Ran}_G(G)\) 得到什么 |
|-------|-------------------------------------|
| 单对象 \(G:*\mapsto A\)（常值到集合 \(A\)） | \(\mathrm{Cont}_A\)：\(X\mapsto (X\to A)\to A\) |
| \(G=Y\mapsto Y^A\)（即右伴随 \(R\)） | \((A\times X)^A=RL(X)\) |
| 任意右伴随 \(R\) | \(RL\)（伴随诱导 monad） |

**关键**：\(\mathrm{Cont}_A\) 是**单对象**常值函子的余密度；整条 \(R=(-)^A\) 的余密度才是 \(RL\)，**不是** \(\mathrm{Cont}_A\)。

---

## 已澄清结论

1. \(T^G:=\mathrm{Ran}_G(G)\) 是 \(\mathcal{C}\) 上单子；UP \(\mathrm{Nat}(H,T^G)\cong\mathrm{Nat}(H\circ G,G)\)；\(\eta,\mu\) 由 UP 唯一性给出。
2. 点值 \(\int_d[\mathcal{C}(c,Gd),Gd]\)；Haskell：`Codensity g c = forall d. (c -> g d) -> g d`。
3. \(L\dashv R\Rightarrow T^R\cong R\circ L\)；对偶 \(\mathrm{Lan}_L(L)\cong L\circ R\)。
4. 柯里化：\(T^{(-)^A}(X)\cong(A\times X)^A\)；元素级 forall 链与 end 一致。
5. \(\mathrm{Cont}_A\) = 单对象 \(G:*\mapsto A\) 的余密度；整条 \(R\) 的余密度才是 \(RL\)。

## 易混点

| 易混 | 澄清 |
|------|------|
| \(\mathrm{Cont}_A\) = \(R\) 的 codensity | 否：\(\mathrm{Cont}_A\) 只对应常值 \(G:*\mapsto A\) |
| \(T^R\) vs \(\mathrm{Ran}_R(\mathrm{Id})\) | \(T^R=\mathrm{Ran}_R(R)\cong RL\)；\(\mathrm{Ran}_R(\mathrm{Id})\cong L\) |
| Codensity 一定是 continuation | 否：continuation 是常值特例；一般 \(G\) 给出一般 \(T^G\) |
| 密度 vs 余密度 | 余密度 = Ran 侧 monad；密度 = Lan 侧 comonad（对偶一句） |
