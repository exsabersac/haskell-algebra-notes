# 函子的作用与组合能力

函子在这套笔记里扮演两层角色：一层是「形状保持的映射」（`fmap`），另一层是「可拼装的一层语法形状」（`Const` / `Sum` / `Product` / `Compose` / `Identity`）。前者管如何把函数抬进结构；后者管树／效果长什么样。

## 1. 函子在做什么：保形映射

对类型构造子 `f`，`Functor` 提供：

```haskell
fmap :: (a -> b) -> f a -> f b
```

直觉：`f` 规定一圈「洞」的布局；`fmap` 只改洞里的值，不改布局。定律（短写）：

```text
fmap id      = id
fmap (g . h) = fmap g . fmap h
```

有了保形映射，才能谈 F-代数 `f a -> a`、`cata`、`foldFree`：先 `fmap` 递归进去，再按一层形状折叠。

## 2. 组合子各自给什么能力

这些是**端函子之间**的运算（在 `End = [C, C]` 里拼新函子），不是普通值上的 `<>`。

| 组合子 | 约等于 | 给的能力 |
|--------|--------|----------|
| `Const c` | 常对象 \(c\) | 叶子／标签；不递归，不吃参数 |
| `Identity` | \(X \mapsto X\) | 单层包装；「再延迟一层」的单位形状 |
| `Sum f g` / `f :+: g` | \(f + g\) | **二选一**：多构造器、多效果指令集 |
| `Product f g` / `f :*: g` | \(f \times g\) | **同时要两边**：配对、并列注解 |
| `Compose f g` / `f :.: g` | \(f \circ g\) | 外层 `f` 里再嵌 `g`；与 monad 复合、层叠效果相关 |

要点：`Sum`/`Product`/`Const` 管的是**一层节点的多项式算术**；`Compose` 管的是**函子复合**（幺半范畴 \((\mathrm{End},\circ,\mathrm{Id})\) 上的乘法）。二者不要混成同一种「加法」。

## 3. 外壳 × 中间式子：常见能力表

同一套「取 \(\mu\)／\(\nu\)」外壳，中间拼法不同，能力就不同：

| 拼法 | 约等于 | 能力／含义 |
|------|--------|------------|
| `Fix f` | \(\mu f\) | 闭递归 ADT；无外部生成元 |
| `Free f a` ≅ `Fix (Sum (Const a) f)` | \(\mu Y.\, a + f Y\) | 开口自由代数／自由 monad；叶子来自 `a` |
| `Free (Sum f g) a` | \(\mu Y.\, a + (f+g)Y\) | 多效果自由混用（à la carte） |
| `Fix (Product f (Const e))` / `Cofree f a` | 形状 × 注解 | 每层挂标签；余侧更标准是 `Cofree` |

记忆口令：

1. **叶从哪来？** 无 / `Const c` / 外部 `a`
2. **一层是选一还是要俩？** `Sum` vs `Product`
3. **最小还是最大解？** `Fix`/`Free`（\(\mu\)）vs `Nu`/`Cofree`（\(\nu\)）

更细的拼法清单见 [常见组合](常见组合.md)。

## 一句话

函子先保证「洞里能安全换值」；再靠 `Const`/`Sum`/`Product`/`Compose`/`Identity` 决定「一层允许什么形状」。`Fix`/`Free`/`Cofree` 只是取不动点的外壳——能力主要来自中间那一截组合。
