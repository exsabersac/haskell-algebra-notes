# 函子范畴上的代数

直觉「组合子给了函子上面的代数结构」——**部分成立**。要说清楚，必须把三层东西拆开：幺半范畴上的 monoid 对象、形状的半环式算术、以及「函子范畴里的 F-代数」真正需要什么。

## 1. 直觉成立的部分

在端函子范畴 \(\mathrm{End}(\mathcal{C}) = [\mathcal{C},\mathcal{C}]\) 里，可以把函子当对象来运算：

- 复合 \(\circ\) 与单位 \(\mathrm{Id}\) → 幺半结构
- 逐点的和／积／常函子 → 一层形状的「算术」

于是 `Free`、`Fix`、效果签名的 `f :+: g` 看起来都像「在函子上做代数」。这个口号有用，但下面三层**不是同一件事**。

## 2. 三层分开说

### 层 1：\((\mathrm{End},\circ,\mathrm{Id})\) 是幺半范畴；其中的 monoid 对象 = Monad

- 张量：函子复合 \(F \otimes G = F \circ G\)
- 单位：恒等函子 \(\mathrm{Id}\)
- **monoid 对象** \((T, \eta : \mathrm{Id}\to T, \mu : T\circ T \to T)\) 恰好是 monad（`return` / `join`）

这是「函子上的代数」里最干净的一层：Monad = 幺半范畴 \((\mathrm{End},\circ,\mathrm{Id})\) 里的幺半群对象。详见 [例子与 Monad](../幺半范畴/例子与Monad.md)。

### 层 2：`Sum` / `Product` / `Const` 是形状算术（半环味道）；≠ \(\circ\)

| 运算 | 含义 | 典型用途 |
|------|------|----------|
| `Sum f g` | 逐点余积 \(f+g\) | 多构造器、多效果 |
| `Product f g` | 逐点积 \(f\times g\) | 并列字段、注解 |
| `Const c` | 常函子 | 叶子、单位「1」或常量标签 |
| `Compose f g` | 复合 \(f\circ g\) | 层叠形状；属层 1 的张量 |

半环口号（启发式，非严格断言）：和 ≈ `Sum`，积 ≈ `Product`，零／幺常出现为 `Const Void` / `Const ()` 一类。  
**关键**：「形状算术」的加法乘法，与「monad 用的乘法」\(\circ\) **不是同一种乘法**。`Compose ≠ Product`，也 ≠ `Sum`。

### 层 3：函子范畴里的 F-代数需要 \(H : \mathrm{End}\to\mathrm{End}\)（HFunctor）

普通 F-代数是：固定自函子 \(F:\mathcal{C}\to\mathcal{C}\)，代数为 \(\varphi : F A \to A\)（对象在 \(\mathcal{C}\)）。

若要把「代数」搬到**函子范畴**里——载体本身是一个函子——则签名也必须是端函子上的自函子，即某种

\[
H : \mathrm{End}(\mathcal{C}) \to \mathrm{End}(\mathcal{C})
\]

（Haskell 口语里的 `HFunctor`／高阶函子一类）。此时「\(H\)-代数」是 \(\Phi : H F \Rightarrow F\)（自然变换），而不是普通的 `f a -> a`。

没有 \(H\)，只拿着 `Sum`/`Product` 拼形状，得到的是**新的端函子**，不是「以函子为载体的 F-代数」本身。

## 3. 和普通 F-代数 / `foldFree` 的对比

| | 普通 F-代数 | 自由代数／`foldFree` | 函子范畴上的 \(H\)-代数 |
|--|-------------|----------------------|-------------------------|
| 载体所在 | \(\mathcal{C}\)（如 `Type`） | 同左；`Free f a` 的折叠 | \(\mathrm{End}(\mathcal{C})\) |
| 结构映射 | `f a -> a` | `foldFree φ`；`φ :: f a -> a` | \(H F \Rightarrow F\) |
| 典型工具 | `cata`、`Fix f` | `Free`、[`foldFree`](../Free/foldFree与cata.md) | 需要 `HFunctor` 级签名 |
| 文档 | [初始代数](../初始代数/) | [Free](../Free/) | 本页层 3 |

口令：

- 谈 `cata` / ADT → 普通初始代数（[初始代数/定义](../初始代数/定义.md)）
- 谈 `Pure` / `foldFree` → 自由代数（[Free](../Free/)）
- 谈「Monad 是函子上的 monoid」→ 层 1（\(\circ\)）
- 谈「`f :+: g` 拼效果」→ 层 2（形状算术）
- 谈「对函子再取代数」→ 先写出 \(H\)，再谈层 3

## 一句话

组合子确实在函子上给出结构，但要标明是哪一种：\(\circ\) 上的 monoid（Monad）、多项式形状算术（`Sum`/`Product`/`Const`），还是真正的 \(H\)-代数（需要 `HFunctor`）。三层口号可以并存，不能收成同一个「algebra」单词。
