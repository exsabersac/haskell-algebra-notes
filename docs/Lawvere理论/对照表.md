# 边界对照：Lawvere / 签名+方程 / finitary monad / 任意 monad

邻近四层描述「代数结构」的语言，边界如下。  
术语：signature、equations、Lawvere theory、finitary monad、arbitrary monad、EM algebra、Kleisli。

相关：[定义与骨架](定义与骨架.md) · [与finitary-monad](与finitary-monad.md) · [List的EM代数与Monoid](../幺半范畴/List的EM代数与Monoid.md)

## 总表

| | Signature + equations | Lawvere theory \(\mathbf{L}\) | Finitary monad \(T\) | Arbitrary monad |
|--|----------------------|-------------------------------|----------------------|-----------------|
| 给什么 | 运算符号表 + 等式公理 | 范畴：对象=自然数幂；态射=运算原型（含定律） | \(\mathbf{Set}\) 上由有限 arity 决定的 monad | 任意 \(T\)（含非 finitary） |
| 载体上的结构 | 解释符号并验证等式 | model：保积 \(M:L\to\mathbf{Set}\) | EM 代数 \(\alpha:TA\to A\) | 同左，但 \(T\) 可非 finitary |
| 与运算的关系 | 语法层最显式 | 运算 = 态射 \(n\to 1\)；定律编进同态集 | \(Tn\) ≅ \(n\)-元「派生运算」空间（经 Kleisli） | 不保证有限元展开 |
| 互译 | 可生成 Lawvere theory（商掉等式） | ↔ finitary monad（自由⊣遗忘 / Kleisli\(^{\mathrm{op}}\)） | ↔ Lawvere theory | **无**一般 Lawvere 对应 |
| 典型例子 | monoid：\(\{\eta^{(0)},\mu^{(2)}\}\)+结合单位律 | \(L_{\mathrm{Mon}}\) | `[]`、`Maybe` | `Cont`（continuation） |
| 编程组合 | 手工 | 理论可用 coproduct / tensor 组合 | monad transformer（无通用配方） | 同左 |

## 分层读法

```text
signature + equations
        │  （编译进同态集）
        ▼
   Lawvere theory L
        │  free ⊣ forgetful
        ▼
   finitary monad T_L     ←── Kleisli^op ──→  L
        │
        │  丢掉「finitary」
        ▼
   arbitrary monad        （如 Cont；未必来自 L）
```

另一条常见线（本仓库已有）：

```text
列表 monad []  ──EM──▶  Monoid
L_Mon ──Mod──▶ Mon     （与上等价的另一包装）
```

## 易混点（短）

1. **Lawvere ≠ 任意 monad**：缺 finitary 则互译失败；Cont 是标准反例。  
2. **Signature 更「语法」**：Lawvere 把运算与定律收成一个范畴的箭头；不再单独列出公理表。  
3. **Model vs EM 代数**：对由 \(\mathbf{L}\) 生成的 \(T_L\)，二者范畴等价；说法不同、对象对应。  
4. **Kleisli vs EM**：Kleisli 重建**理论**（运算空间）；EM 描述**模型**（如何求值）。不要混用箭头方向。

---

## 一句话

Signature+等式 ⊂（呈现为）Lawvere theory ↔ finitary monad ⊂ 任意 monad；continuation 落在最外层且通常无对应的经典 Lawvere theory。
