## 1. 总表

| | Signature + equations | Lawvere theory \(\mathbf{L}\) | Finitary monad \(T\) | Arbitrary monad |
|--|----------------------|-------------------------------|----------------------|-----------------|
| 给什么 | 运算符号表 + 等式公理 | 范畴：对象=自然数幂；态射=运算原型（含定律） | \(\mathbf{Set}\) 上由有限 arity 决定的 monad | 任意 \(T\)（含非 finitary） |
| 载体上的结构 | 解释符号并验证等式 | model：保积 \(M:L\to\mathbf{Set}\) | EM 代数 \(\alpha:TA\to A\) | 同左，但 \(T\) 可非 finitary |
| 与运算的关系 | 语法层最显式 | 运算 = 态射 \(n\to 1\)；定律编进同态集 | \(Tn\) ≅ \(n\)-元「派生运算」空间（经 Kleisli） | 不保证有限元展开 |
| 互译 | 可生成 Lawvere theory（商掉等式） | ↔ finitary monad（自由⊣遗忘 / Kleisli\(^{\mathrm{op}}\)） | ↔ Lawvere theory | **无**一般 Lawvere 对应 |
| 典型例子 | monoid：\(\{\eta^{(0)},\mu^{(2)}\}\)+结合单位律 | \(L_{\mathrm{Mon}}\) | `[]`、`Maybe`、Writer、有限 Reader/State、NE 等（见 [多种finitary-monad](多种finitary-monad.md)） | `Cont`（continuation） |
| 编程组合 | 手工 | 理论可用 coproduct / tensor 组合 | monad transformer（无通用配方） | 同左 |

## 2. 分层读法

```text
signature + equations
        │  （编译进同态集）
        ▼
   Lawvere theory L
        │  free ⊣ forgetful
        ▼
   finitary monad T_L     ←── Kleisli^op|fin ──→  L
        │
        │  丢掉「finitary」
        ▼
   arbitrary monad        （如 Cont；未必来自 L）
```

另一条本仓库已有的线：

```text
列表 monad []  ──EM──▶  Monoid
L_Mon ──Mod──▶ Mon     （与上等价的另一包装）
```

Maybe 线（[副作用与Maybe](副作用与Maybe.md)）：

```text
签名 { raise⁽⁰⁾ }  →  L_raise  →  T a ≅ a⁰+a¹ ≅ Maybe a
```

## 3. 何时用哪一副眼镜

| 你想做的事 | 更合适的层 | 原因（机制） |
|------------|------------|--------------|
| 写下运算符号与等式公理 | signature + equations | 语法最直白；易与课本 universal algebra 对齐 |
| 把「所有同类代数」收成一个范畴对象 | Lawvere theory | 对象=幂、态射=运算；模型范畴一次给出 |
| 谈自由代数、`return`/`join`、do-记法 | finitary monad | \(T=U\circ F\)；编程接口熟悉 |
| 谈 EM 代数 / `mconcat` | monad 的 EM（常即 finitary） | 求值映射 \(\alpha:TA\to A\) |
| 谈 Kleisli / `>=>` | Kleisli | 重建理论时用 \(\mathrm{Kl}^{\mathrm{op}}\)；编程里是「效果箭头」 |
| `Cont`、完整 handler、任意高阶效果 | 超出经典 Lawvere；用 monad / 代数效应等 | 缺 finitary 展开则互译失败 |

\(\mathbf{Law}\) 中的态射：保积且与 \(I\) 交换的函子 \(L\to L'\)。  
机制：按签名翻译运算。

| \(L_{\mathrm{Semigroup}}\to L_{\mathrm{Monoid}}\) | monoid 模型预复合 → semigroup 模型（忘 \(\eta\)） |

## 5. 易混点（短）

1. **Lawvere ≠ 任意 monad**：缺 finitary 则互译失败；`Cont` 是标准反例。  
2. **Signature 更「语法」**：Lawvere 把运算与定律收成一个范畴的箭头；不再单独列出公理表。  
3. **Model vs EM 代数**：对由 \(\mathbf{L}\) 生成的 \(T_L\)，二者范畴等价；说法不同、对象对应。  
4. **Kleisli vs EM**：Kleisli 重建**理论**（运算空间）；EM 描述**模型**（如何求值）。不要混用箭头方向。  
5. **自由 monoid \(n^*\) vs \(L_{\mathrm{Mon}}\)**：前者是一个（族）特殊模型；后者是整类的共性范畴（见 [幺半群理论](幺半群理论.md) §4）。

## 一句话

Signature+等式 ⊂（呈现为）Lawvere theory ↔ finitary monad ⊂ 任意 monad；continuation 落在最外层且通常无对应的经典 Lawvere theory。选用哪一层，看你要语法、共性范畴、还是 `return`/`join`／EM 求值。
