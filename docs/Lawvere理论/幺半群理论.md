# 幺半群的 Lawvere 理论 \(L_{\mathrm{Mon}}\)

最简单的非平凡例子：描述**所有** monoid 共性的单一理论；其模型范畴等价于 \(\mathbf{Mon}\)。  
术语：free monoid、\(n^*\)、\(L_{\mathrm{Mon}}\)、\(\mathrm{Mod}(L_{\mathrm{Mon}},\mathbf{Set})\)。

相关：[模型](模型.md) · [与finitary-monad](与finitary-monad.md) · [List的EM代数与Monoid](../幺半范畴/List的EM代数与Monoid.md) · [自由幺半群与列表](../幺半范畴/自由幺半群与列表.md)
更细的原文顺序见 [CTFP原文细讲](CTFP原文细讲.md)。

可运行：[`src/Lawvere/Demo.hs`](../../src/Lawvere/Demo.hs) 横幅 `[1]` `[2]` `[3]`。

## 1. 必须有的态射

相对平凡骨干 \(\mathbf{F}^{\mathrm{op}}\)，monoid 理论至少要加：

| 态射 | 方向 | 为何「有趣」 |
|------|------|--------------|
| 单位 \(\eta\) | \(0\to 1\) | \(\mathbf{F}\) 中不存在对应的 \(1\to 0\)（单点不能映入空集） |
| 乘法原型 | \(2\to 1\) 中的成员 | 在模型里解释为 \(a\times a\to a\) |

```haskell
-- Demo [1]
op0 :: Monoid m => m             -- η : 0 → 1
op0 = mempty

op2 :: Monoid m => m -> m -> m   -- μ : 2 → 1
op2 = (<>)
```

三种模型上的解释（同一理论、不同 \(M\)）：

| 模型 | `op0` | `op2 x y` |
|------|-------|-----------|
| `(Sum Int, 0, +)` | `Sum 0` | `Sum (getSum x + getSum y)` |
| `([a], [], ++)` | `[]` | `x ++ y` |
| `(Endo a, id, .)` | `Endo id` | `Endo (f . g)`（若 `x=Endo f`, `y=Endo g`） |

## 2. \(\mathbf{L}_{\mathrm{Mon}}(2,1)\) 有多大？

仅用 monoid 运算能写出的「二元导出运算」：忽略两边给单位、两个投影、\(ab\)、\(ba\)、\(aa\)、\(bb\)、\(aab\)、……  
个数 = **两个生成元的自由 monoid** 的元素个数。

**机制**：

1. 自由 monoid 本身是一个模型；
2. 在自由模型里，上述每个词对应**不同**函数 \(a\times a\to a\)；
3. 理论必须足够大以容纳自由情形——其它模型可以塌缩若干态射，但理论侧不能先塌缩。

记 \(n^*\) 为 \(n\) 个生成元的自由 monoid。取

\[
\mathbf{L}_{\mathrm{Mon}}(m,n) \;=\; \mathbf{Mon}(n^*,\, m^*)
\]

即 \(\mathbf{L}_{\mathrm{Mon}}\) 是**自由 monoid 范畴的 opposite**（注意 \(m,n\) 参数对调：理论箭头 \(m\to n\) 对应 monoid 同态 \(n^*\to m^*\)）。

### Demo：词 = 态射 \(2\to 1\) 的 stand-in

```haskell
-- Demo [2]
data Gen = A | B
type Word2 = [Gen]   -- 2* 的元素

-- 在具体 monoid 上解释词：A ↦ 第一自变量，B ↦ 第二
applyWord :: Monoid m => Word2 -> m -> m -> m
applyWord w x y = mconcat (map pick w)
  where
    pick A = x
    pick B = y

-- 长度 ≤ maxLen 的全部词（含 ε）
wordsUpTo :: Int -> [Word2]
```

| 词 | 作为 \(2\to 1\) 的语义 | `applyWord` 在 `(x,y)` 上 |
|----|------------------------|---------------------------|
| \(\varepsilon\)（`[]`） | 忽略自变量，返回单位 | `mempty` |
| `A` | 投影 \(\pi_1\) | `x` |
| `B` | 投影 \(\pi_2\) | `y` |
| `AB` | 乘法 | `x <> y` |
| `BA` | 翻转移位乘法 | `y <> x` |
| `AA` | 对角后乘 | `x <> x` |
| `BB` | | `y <> y` |

`wordsUpTo 2` 枚举 \(\varepsilon,A,B,AA,AB,BA,BB\)（共 7 个）；在 `(Sum 2, Sum 3)` 上可逐词求值——自由情形下这些是不同态射的影子。

```text
cabal run algebra-demos
-- [2] L(2,1) free-words --
  count(|w|≤2) = 7
  ε   ⇒  \_ _ → unit
  A   ⇒  \x y → x
  …
  interpret on (Sum 2, Sum 3):
    apply AB ↦ Sum 5
```

## 3. 模型范畴

\[
\mathrm{Mod}(\mathbf{L}_{\mathrm{Mon}},\,\mathbf{Set}) \;\simeq\; \mathbf{Mon}
\]

每个 monoid 是一个保积模型；monoid 同态对应模型间的自然变换（见 [模型](模型.md) §4）。

与列表 monad 路线汇合：

```text
EM([])  ≃  Mon  ≃  Mod(L_Mon, Set)
```

- EM 侧：结构映射 `mconcat : [a] → a`（见 [List的EM代数与Monoid](../幺半范畴/List的EM代数与Monoid.md)）；
- Lawvere 侧：保积函子解释 \(\eta,\mu\) 及全部导出词；
- \(L_{\mathrm{Mon}}\) 生成的 finitary monad 恰是列表 monad（见 [与finitary-monad](与finitary-monad.md)）。

定律检查（Demo `[3]`）确认所选解释确实是 monoid：

```haskell
checkMonoidLaws x y z =
  and [ (x<>y)<>z == x<>(y<>z)
      , mempty <> x == x
      , x <> mempty == x ]
```

## 4. 与「单个自由 monoid」对照

| | 单个自由 monoid \(n^*\) | \(L_{\mathrm{Mon}}\) |
|--|------------------------|----------------------|
| 概括范围 | 再商掉部分态射可得许多 monoid | **所有** monoid 的共性 |
| 个数 | 每个 \(n\) 一个 | 一个理论装进所有 \(n^*\) |
| 与模型 | \(n^*\) 是一个特殊模型（自由的） | \(\mathrm{Mod}\simeq\mathbf{Mon}\) |
| Haskell | `[Gen]`（\(n=\|\)字母表\(\|\)） | `Monoid m` 的全体实例 + 词空间 |

单个自由 monoid 已经「管」很多商；Lawvere 理论再把**所有**有限生成自由 monoid 的箭头空间收成一个范畴，从而一次描述整类。

## 5. 从词到求值：万有性接点

自由 monoid 的 UP：任意 \(f:\{\mathrm{A},\mathrm{B}\}\to M\) 唯一扩展为 monoid 同态 \(\varphi:[\![\mathrm{A},\mathrm{B}]\!]\to M\)。  
Demo `[4]` 用 `foldMap` 做这件事：

```haskell
-- 词 [A,B,A] 在 (Sum,+) 上：A↦2, B↦3
foldMap interpretSum [A, B, A]  -- Sum 7
```

这与 `applyWord` 一致：`applyWord` 固定二元槽位；`foldMap` 对任意长度的生成元列表求值。二者都是「理论里的表达式 ↦ 模型里的值」。

---

## 一句话

\(L_{\mathrm{Mon}}\) ≃ 自由 monoid 范畴的 opposite；\(\mathrm{Mod}(L_{\mathrm{Mon}},\mathbf{Set})\simeq\mathbf{Mon}\)；\(\mathbf{L}(2,1)\) 的「有趣」态射与两生成元自由 monoid 的词一一对应——Demo 用 `Word2` / `applyWord` / `wordsUpTo` 作 stand-in。
