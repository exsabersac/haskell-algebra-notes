# Lawvere 理论：定义与骨架

从 **universal algebra** 到 Lawvere theory 的骨干：有限集合范畴 → 骨架 → 对偶 → 嵌入函子 \(I_L\)。  
术语：arity、skeleton、FinSet、\(\mathbf{F}\)、\(\mathbf{F}^{\mathrm{op}}\)、Lawvere theory、basic product operations、interesting morphisms。

相关：[模型](模型.md) · [幺半群理论](幺半群理论.md) · [对照表](对照表.md) · Demo `[1]`

---

## 1. Universal algebra：运算与定律

monoid、group、ring 等在最朴素一层是：一组 **\(n\)-元运算**（operations）加上一组**全称量化**的等式定律（equational laws）。

| 结构 | 运算 | 定律（全称等式） |
|------|------|------------------|
| monoid | 二元 \(\mu\) + 零元 \(\eta\)（单位） | 结合；左右单位 |
| group | 再加一元逆 | 左右逆 |
| ring | 两套二元运算等 | 分配、环公理… |

**arity** = 运算的元数。一般 \(n\)-元运算是从载体的 \(n\) 次幂映回载体：

\[
\alpha_n : a^n \to a
\]

零元（nullary）运算是从终对象（\(a^0 \cong 1\)）到 \(a\) 的态射。

因此：只要范畴里有一个「生成对象」\(a\)，且其余对象都是它的有限幂，同态集里编码运算与定律，就得到 Lawvere theory 的核心理念。

> **字段（field）不在此框架内**：零关于乘法无逆，逆律不能对全部元素全称量化。

范畴陈述先，再形状：

```haskell
-- nullary / unary / binary 作为函数形状（幂 → 载体）
unit  :: ()     -> a          -- a^0 → a
inv   :: a      -> a          -- a^1 → a
mul   :: (a, a) -> a          -- a^2 → a
```

Demo `[1]` 把 monoid 的 \(\eta,\mu\) 写成 `op0 = mempty`、`op2 = (<>)`，并在三种具体载体上解释（见下节「幂」直觉后接 [幺半群理论](幺半群理论.md)）。

## 2. 路线图（CTFP）

| 步骤 | 对象 | 作用 |
|------|------|------|
| 1 | \(\mathbf{FinSet}\) | 有限集合范畴；对象由单点经 **coproduct** 生成 |
| 2 | \(\mathbf{F}\) | \(\mathbf{FinSet}\) 的 **skeleton**：同构对象合并；对象 ≅ 自然数（含 0） |
| 3 | \(\mathbf{F}^{\mathrm{op}}\) | 对偶：coproduct ↔ product；injection ↔ projection |
| 4 | \(\mathbf{L}\) | Lawvere theory：在 \(\mathbf{F}^{\mathrm{op}}\) 骨干上加「有趣」的 \(n\)-元运算态射 |
| 5 | \(M\in\mathrm{Mod}(\mathbf{L},\mathbf{Set})\) | **model**：保有限积的函子 \(\mathbf{L}\to\mathbf{Set}\) |

```text
FinSet  →  F（skeleton）  →  F^op  →  L（经 I_L）  →  models
```

## 3. FinSet 与骨架 \(\mathbf{F}\)

\(\mathbf{FinSet}\) 含 \(\varnothing\)、单点集 \(1\)、两点集 \(2=1+1\) 等。所有有限集可由单点用 coproduct 拼出（空集视为零元 coproduct）。

**问题**：\(\mathbf{Set}\) 里的 coproduct **不严格结合**。例如 \(1+\varnothing\)、\(\varnothing+1\)、\(1\) 彼此同构但作为集合不相等；「唯一空集 / 唯一单点」的直觉在严格相等下会碎。

**Skeleton** \(\mathbf{F}\)：每个同构类取一个代表。对象记为自然数 \(n\)（元素个数）；coproduct 扮演加法。态射 = 有限集合之间的函数（落在代表上）。

| 态射（在 \(\mathbf{F}\)） | 含义 |
|--------------------------|------|
| \(\varnothing\to n\) | 唯一（初对象） |
| \(n\to\varnothing\)（\(n>0\)） | 不存在 |
| \(1\to n\) | \(n\) 条注入（选第 \(k\) 个点） |
| \(n\to 1\) | 唯一（到终对象） |
| \(m\to n\) | 从 \(n\) 元里选 \(m\) 个（可重复）的映射 |

Haskell 里「点数」直觉（非正式；真正的 \(\mathbf{F}\) 是同构类）：

```haskell
-- 对象 n ≅ 有 n 个槽位的有限集（skeleton 代表）
-- 态射 m → n ≅ 函数 {1..m} → {1..n}
type FinMor = Int -> Int   -- 仅示意：定义域/值域的基数要另外记住

-- 例：2 → 3 的全部函数个数 = 3^2 = 9
finMorCount :: Int -> Int -> Int
finMorCount m n = n ^ m
```

## 4. 为何需要 \(\mathbf{F}^{\mathrm{op}}\)

Lawvere theory 的对象应是某个对象 \(1\) 的**幂**（有限积），而 \(\mathbf{F}\) 自然给出的是 **coproduct**。

**机制**（不是口号）：取 **contravariant** 嵌入——把 \(\mathbf{F}\) 的箭头反向——则：

| 在 \(\mathbf{F}\) | 在 \(\mathbf{F}^{\mathrm{op}}\) / \(\mathbf{L}\) |
|-------------------|-----------------------------------------------|
| coproduct \(m+n\) | product \(m\times n\)（对象仍记 \(m,n\)） |
| injection \(1\to n\) | projection \(n\to 1\)（常写 \(1^n\to 1\)） |
| 常值 \(n\to 1\) | 对角 / 复制 \(1\to 1^n\) |

具体对应：

- \(\mathbf{F}\) 中 \(2=1+1\) ↦ \(\mathbf{L}\) 中 \(1\times 1=1^2\)。
- 投影 \(p_k:1^n\to 1\)：原型「\(n\) 个变量里只取第 \(k\) 个」。
- 对角 \(1\to 1^n\)：变量复制。

幂 / 积在 Haskell 里就是元组（有限积的具体化）：

```haskell
-- 对象 n 在模型里变成 a^n ≅ n 元组（见「模型」篇）
type Pow0 a = ()           -- a^0
type Pow1 a = a            -- a^1
type Pow2 a = (a, a)       -- a^2
type Pow3 a = (a, a, a)    -- a^3

-- 「无聊」结构：投影 / 对角（basic product operations）
π1 :: (a, a) -> a
π1 (x, _) = x

π2 :: (a, a) -> a
π2 (_, y) = y

diag :: a -> (a, a)
diag x = (x, x)
```

这些来自 \(I_L\) 的态射叫 **basic product operations**（投影、对角等「无聊」积结构）。真正区分不同代数理论的是下面的 **interesting morphisms**。

## 5. 定义：\(I_L:\mathbf{F}^{\mathrm{op}}\to\mathbf{L}\)

**Lawvere theory** 是范畴 \(\mathbf{L}\) 配上函子

\[
I_{\mathbf{L}} : \mathbf{F}^{\mathrm{op}} \to \mathbf{L}
\]

满足：

1. **对对象双射**（常说成 identity-on-objects：对象都用自然数 \(0,1,2,\ldots\) 标记）；
2. **保有限积**：\(I_L(m\times n)=I_L(m)\times I_L(n)\)（\(\mathbf{F}^{\mathrm{op}}\) 的积 = \(\mathbf{F}\) 的 coproduct）。

同态集 \(\mathbf{L}(m,n)\) 一般比 \(\mathbf{F}^{\mathrm{op}}\) **更丰富**：

| 来源 | 名称 | 例子 |
|------|------|------|
| \(I_L\) 的像 | basic product operations | 投影 \(1^n\to 1\)、对角 \(1\to 1^n\) |
| 额外添加 | interesting morphisms | 乘法 \(2\to 1\)、单位 \(0\to 1\)、逆 \(1\to 1\)… |

定律（全称等式）编进这些同态集的**相等关系**里：哪些复合箭头被认定为同一态射。

因结构简单，一般态射 \(n\to m\)（即 \(1^n\to 1^m\)）是若干 \(n\to 1\) 的积（hom-函子连续：返回积的箭头 = 箭头的积）。

```haskell
-- 「有趣」：真正的代数运算（monoid 例；Demo op0 / op2）
op0 :: Monoid m => m                 -- η : 0 → 1 的解释
op0 = mempty

op2 :: Monoid m => m -> m -> m       -- μ : 2 → 1 的解释
op2 = (<>)

-- 复合运算 n → m 可看成 m 个「n → 1」的并排
-- 例如 2 → 2 可由两个 2 → 1 拼出：(f,g) : a² → a²
pair2 :: (a -> a -> a) -> (a -> a -> a) -> (a, a) -> (a, a)
pair2 f g (x, y) = (f x y, g x y)
```

## 6. Lawvere 理论之间的态射；平凡理论

范畴 \(\mathbf{Law}\)：对象是 Lawvere theories；态射是**保有限积且与 \(I\) 交换**的函子。  
机制：\(F:L\to L'\) 满足 \(F(m\times n)=Fm\times Fn\) 且 \(F\circ I_L=I_{L'}\)。

解释：把一个理论的运算「翻译」进另一个（例如把群乘法当 monoid 乘法，忘掉逆）。Demo `[6]` 草图：Semigroup 的理论映入 Monoid 的理论（只保留 `op2`，忘掉 `op0`）；模型侧则是「忘掉单位」。

最简例子：\(\mathbf{L}=\mathbf{F}^{\mathrm{op}}\)，\(I_L=\mathrm{id}\)。无额外运算与定律——是 \(\mathbf{Law}\) 的**初对象**。其模型范畴 \(\simeq\mathbf{Set}\)（见 [模型](模型.md)）。

## 7. 无聊 vs 有趣：一张表

| | boring（basic product ops） | interesting |
|--|------------------------------|-------------|
| 来源 | \(I_L:\mathbf{F}^{\mathrm{op}}\to\mathbf{L}\) | \(\mathbf{L}\) 相对 \(\mathbf{F}^{\mathrm{op}}\) 多出的同态 |
| 作用 | 搭好幂 / 投影 / 复制 | 编码具体代数运算与定律 |
| 换理论时 | 共用骨干 | 改变 → 换理论 |
| Haskell 影子 | `π1`/`π2`/`diag` | `op0`/`op2`/`inv`… |

---

## 一句话

Lawvere theory = 以 \(\mathbf{F}^{\mathrm{op}}\) 为积骨干、对象为自然数幂、同态集编码 \(n\)-元运算与等式定律的范畴；嵌入 \(I_L\) 对对象双射且保有限积；boring 箭头搭积，interesting 箭头定义代数。
