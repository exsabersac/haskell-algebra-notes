# Lawvere 理论：定义与骨架

从 **universal algebra** 到 Lawvere theory 的骨干：有限集合范畴 → 骨架 → 对偶 → 嵌入函子 \(I_L\)。  
术语：arity、skeleton、FinSet、\(\mathbf{F}\)、\(\mathbf{F}^{\mathrm{op}}\)、Lawvere theory、basic product operations。

相关：[模型](模型.md) · [幺半群理论](幺半群理论.md) · [对照表](对照表.md)

---

## 1. Universal algebra：运算与定律

monoid、group、ring 等在最朴素一层是：一组 **\(n\)-元运算**（operations）加上一组**全称量化**的等式定律（equational laws）。

- monoid：二元结合运算 + 单位元（可看成 **nullary** 运算）+ 单位律。
- group：再加一元逆运算 + 左右逆律。
- ring：两套二元运算及更多定律。

**arity** = 运算的元数。一般 \(n\)-元运算是从载体的 \(n\) 次幂映回载体：

\[
\alpha_n : a^n \to a
\]

nullary 运算是从终对象（\(a^0\)）到 \(a\) 的态射。  
因此：只要范畴里有一个「生成对象」\(a\)，且对象都是它的幂，同态集里编码运算与定律，就得到 Lawvere theory 的核心理念。

> 字段（field）不在此框架内：零关于乘法无逆，逆律不能全称量化。

短 Haskell（运算形状，非完整理论）：

```haskell
-- nullary / unary / binary 作为函数形状
unit  :: ()       -> a          -- a^0 → a
inv   :: a        -> a          -- a^1 → a
mul   :: (a, a)   -> a          -- a^2 → a
```

## 2. 路线图

| 步骤 | 对象 | 作用 |
|------|------|------|
| 1 | \(\mathbf{FinSet}\) | 有限集合范畴；对象由单点经 **coproduct** 生成 |
| 2 | \(\mathbf{F}\) | \(\mathbf{FinSet}\) 的 **skeleton**：同构对象合并；对象 ≅ 自然数（含 0） |
| 3 | \(\mathbf{F}^{\mathrm{op}}\) | 对偶：coproduct ↔ product；injection ↔ projection |
| 4 | \(\mathbf{L}\) | Lawvere theory：在 \(\mathbf{F}^{\mathrm{op}}\) 骨干上加「有趣」的 \(n\)-元运算态射 |
| 5 | \(M\in\mathrm{Mod}(\mathbf{L},\mathbf{Set})\) | **model**：保有限积的函子 \(\mathbf{L}\to\mathbf{Set}\) |

```text
FinSet  →  F（skeleton）  →  F^op  →  L（经 I_L）  →  models
```

---

## 3. FinSet 与骨架 \(\mathbf{F}\)

\(\mathbf{FinSet}\) 含 \(\varnothing\)、单点集 \(1\)、两点集 \(2=1+1\) 等。coproduct 在 \(\mathbf{Set}\) 中**不严格结合**（\(1+\varnothing\)、\(\varnothing+1\)、\(1\) 同构但不相等）。

**Skeleton** \(\mathbf{F}\)：每个同构类取一个代表。对象记为自然数 \(n\)（元素个数）；coproduct 扮演加法。态射 = 有限集合之间的函数（在同构类上的代表）。

直觉例子：

| 态射方向（在 \(\mathbf{F}\)） | 含义 |
|------------------------------|------|
| \(\varnothing\to n\) | 唯一（初对象） |
| \(1\to n\) | \(n\) 条注入 |
| \(n\to 1\) | 唯一（到终对象） |
| \(m\to n\) | 从 \(n\) 元里选 \(m\) 个（可重复）的映射 |

---

## 4. 为何需要 \(\mathbf{F}^{\mathrm{op}}\)

Lawvere theory 的对象应是某个对象 \(1\) 的**幂**（有限积），而 \(\mathbf{F}\) 自然给出的是 **coproduct**。  
**Contravariant** 嵌入把 coproduct 变成 product、injection 变成 projection，故骨干取 \(\mathbf{F}^{\mathrm{op}}\)。

- \(\mathbf{F}\) 中 \(2=1+1\) ↦ \(\mathbf{F}^{\mathrm{op}}\) / \(\mathbf{L}\) 中 \(1\times 1=1^2\)。
- 投影 \(p_k:1^n\to 1\)：原型「\(n\) 个变量里只取第 \(k\) 个」。
- 对角 \(1\to 1^n\)：来自 \(\mathbf{F}\) 中常数映射 \(n\to 1\) 的对偶——变量复制。

口语：\(\mathbf{F}\) 像 \(\mathbf{L}\) 的「对数」——积结构由骨架搬来。

---

## 5. 定义：\(I_L:\mathbf{F}^{\mathrm{op}}\to\mathbf{L}\)

**Lawvere theory** 是范畴 \(\mathbf{L}\) 配上函子

\[
I_{\mathbf{L}} : \mathbf{F}^{\mathrm{op}} \to \mathbf{L}
\]

满足：

1. **对对象双射**（常说成 identity-on-objects：对象都用自然数 \(0,1,2,\ldots\) 标记）；
2. **保有限积**：\(I_L(m\times n)=I_L(m)\times I_L(n)\)（\(\mathbf{F}^{\mathrm{op}}\) 的积 = \(\mathbf{F}\) 的 coproduct）。

同态集 \(\mathbf{L}(m,n)\) 一般比 \(\mathbf{F}^{\mathrm{op}}\) **更丰富**：多出来的态射是真正的代数运算与定律的编码。来自 \(I_L\) 的态射叫 **basic product operations**（投影、对角等「无聊」结构）；其余是「有趣」的 \(n\)-元运算。

因结构简单，一般态射 \(n\to m\)（即 \(1^n\to 1^m\)）是若干 \(n\to 1\) 的积（hom-函子连续）。

---

## 6. Lawvere 理论之间的态射；平凡理论

范畴 \(\mathbf{Law}\)：对象是 Lawvere theories；态射是保有限积且与 \(I\) 交换的函子。  
解释直觉：把一个理论「读进」另一个（例如把群乘法当 monoid 乘法，忘掉逆）。

最简例子：\(\mathbf{L}=\mathbf{F}^{\mathrm{op}}\)，\(I_L=\mathrm{id}\)。无额外运算与定律——是 \(\mathbf{Law}\) 的**初对象**。

---

## 一句话

Lawvere theory = 以 \(\mathbf{F}^{\mathrm{op}}\) 为积骨干、对象为自然数幂、同态集编码 \(n\)-元运算与等式定律的范畴；嵌入 \(I_L\) 对对象双射且保有限积。
