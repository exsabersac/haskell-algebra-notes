# Lawvere 理论的模型

一个 Lawvere theory \(\mathbf{L}\) 描述「一类代数的共性」；具体代数是它的 **model**。  
术语：model、product-preserving、up to isomorphism、\(\mathrm{Mod}(\mathbf{L},\mathbf{Set})\)、sort、natural transformation。

相关：[定义与骨架](定义与骨架.md) · [幺半群理论](幺半群理论.md) · [与finitary-monad](与finitary-monad.md) · Demo `[1]` `[3]`

---

## 1. 定义

\(\mathbf{L}\) 的一个 **model**（亦称 \(\mathbf{L}\) 上的代数）是保有限积的函子

\[
M : \mathbf{L} \to \mathbf{Set},
\qquad
M(a\times b) \;\cong\; Ma \times Mb
\]

注意：积只需**保到同构**（up to isomorphism）。严格相等会杀掉绝大多数有趣例子（\(\mathbf{Set}\) 里的笛卡尔积本身就不严格结合）。

记 \(a = M(1)\)（**sort**；此处为 single-sorted）。则：

| \(\mathbf{L}\) 中的态射 | 经 \(M\) 得到 |
|-------------------------|---------------|
| \(0\to 1\)（nullary） | 函数 \(1\to a\)（挑一个元素） |
| \(1\to 1\)（unary） | 函数 \(a\to a\) |
| \(2\to 1\)（binary） | 函数 \(a\times a\to a\) |
| \(m\to n\) | 函数 \(a^m\to a^n\) |

多个 \(\mathbf{L}\)-态射可能被 \(M\) 塌缩成 \(\mathbf{Set}\) 里同一函数（非自由模型会「认不出」某些词的差别）。

因定律皆全称等式，每个 Lawvere theory 都有**平凡模型**：常值函子，一切对象映到单点集，一切态射映到恒等。

## 2. 在具体类型上解释运算（Haskell）

「做一个模型」= 选定载体 \(a=M(1)\)，把理论里的运算解释成该载体上的函数，并让方程成立。

```haskell
-- 模型指定：载体 a = M(1)，以及运算的解释
-- monoid 理论：η : 0→1、μ : 2→1
op0 :: Monoid m => m                 -- Demo: op0 = mempty
op0 = mempty

op2 :: Monoid m => m -> m -> m       -- Demo: op2 = (<>)
op2 = (<>)

-- 三种模型（Demo [1]）
--   (Sum Int,  0, +)     ：加法 monoid
--   ([Char],   [], ++)   ：列表 monoid
--   (Endo Int, id, .)    ：自同态 monoid（Endo f <> Endo g = Endo (f . g)）
```

运行时对照：

```text
cabal run algebra-demos
-- [1] nullary/binary ops --
  model (Sum,0,+):  op0 = Sum 0 ;  op2 (Sum 2) (Sum 3) = Sum 5
  model ([a],[],++): op0 = "" ;  op2 "ab" "cd" = "abcd"
  model (Endo Int,id,.): …
```

函子性在这里的具体含义：\(\mathbf{L}\) 里的复合与恒等被解释成函数复合与 `id`；积结构被解释成元组上的投影 / 配对（见 [定义与骨架](定义与骨架.md) 的 `π1`/`π2`/`diag`）。

## 3. 定律在模型里检查（Demo `[3]`）

理论里的等式定律，在模型里变成载体上的可检查等式：

```haskell
-- Demo: checkMonoidLaws / checkMonoidLawsReport
checkMonoidLaws :: (Eq m, Monoid m) => m -> m -> m -> Bool
checkMonoidLaws x y z =
  and
    [ (x <> y) <> z == x <> (y <> z)   -- 结合
    , mempty <> x == x                 -- 左单位
    , x <> mempty == x                 -- 右单位
    ]
```

| 理论侧 | 模型侧 |
|--------|--------|
| 同态集里认定 \((xy)z = x(yz)\) | 对所有取出的 \(x,y,z\)，`<>` 结合 |
| 认定 \(\eta\cdot x = x = x\cdot\eta\) | `mempty <> x == x` 等 |

Demo 在 `Sum`、`[Char]`、`Endo` 上打印 `PASS`/`FAIL`。这是教育检查，不是形式化证明。

## 4. 模型之间的自然变换

两模型 \(M,N\)（载体 \(a=M1\)、\(b=N1\)）之间的自然变换是一族

\[
\mu_n : Mn \to Nn
\quad\text{即}\quad
\mu_n : a^n \to b^n
\]

自然性保证 \(n\)-元运算被保持：对 \(f:n\to 1\)，

\[
Nf \circ \mu_n = \mu_1 \circ Mf
\]

即：先运算再映射 = 先映射再运算。对 monoid，这正是 **monoid 同态** 的内容：

```haskell
-- μ₁ : a → b 保持运算（自然性在 n=0,2 的实例）
-- μ₁ mempty_a     = mempty_b
-- μ₁ (x <>_a y)   = μ₁ x <>_b μ₁ y
```

模型与自然变换组成范畴 \(\mathrm{Mod}(\mathbf{L},\mathbf{Set})\)。

---

## 5. 平凡理论：\(\mathrm{Mod}(\mathbf{F}^{\mathrm{op}},\mathbf{Set})\simeq\mathbf{Set}\)

对初对象理论 \(\mathbf{L}=\mathbf{F}^{\mathrm{op}}\)（无额外运算）：

- 模型完全由 \(M(1)\) 决定，且 \(M(1)\) 可以是任意集合；
- 模型间的自然变换由分量 \(\mu_1:M1\to N1\) 唯一决定。

故 \(\mathrm{Mod}(\mathbf{F}^{\mathrm{op}},\mathbf{Set})\) **等价于** \(\mathbf{Set}\)。

这为后文「遗忘函子落到 \(\mathbf{Set}\)」提供支点：\(\mathbf{F}^{\mathrm{op}}\) 是 \(\mathbf{Law}\) 的初对象 ⇒ 任意 \(\mathbf{L}\) 有唯一 \(\mathbf{F}^{\mathrm{op}}\to\mathbf{L}\)，诱导

\[
\mathrm{Mod}(\mathbf{L},\mathbf{Set}) \to \mathrm{Mod}(\mathbf{F}^{\mathrm{op}},\mathbf{Set}) \simeq \mathbf{Set}.
\]

该复合就是遗忘 \(U:M\mapsto M(1)\)（见 [与finitary-monad](与finitary-monad.md)）。

## 6. 与「具体代数」对照

| | Lawvere theory \(\mathbf{L}\) | model \(M\) |
|--|------------------------------|-------------|
| 角色 | 一类结构的抽象语法／定律 | 某一个具体代数 |
| 对象 | 自然数（幂） | 集合的幂 \(a^n\) |
| 态射 | 运算原型 + 结构投影 | 实际函数 |
| 定律 | 编进同态集的相等 | 载体上必须成立的等式 |
| 全体模型 | — | \(\mathrm{Mod}(\mathbf{L},\mathbf{Set})\) |
| monoid 例 | \(L_{\mathrm{Mon}}\) | 每个 `Monoid m` 的实例 |

---

## 一句话

Model = 保有限积（至同构）的 \(M:\mathbf{L}\to\mathbf{Set}\)；载体 \(a=M(1)\) 上解释运算并验证定律；平凡理论的模型范畴 \(\simeq\mathbf{Set}\)；模型间的箭头是保持运算的自然变换（monoid 时即 monoid 同态）。
