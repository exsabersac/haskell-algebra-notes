## 二 · 始与终　`02:05–03:29`

参考：DaoFP ch.1 Elements；CTFP 1.5 Initial / Terminal

| 时间 | 旁白 | 画面 / 代码 |
|---|---|---|
| 02:06 | 先把定义钉死。始对象——记作零——对每个对象 a，从零到 a 的箭头存在且唯一。写成 Hom 的话：Hom 零 a 是单点集。存在，保证有路；唯一，保证没有两条可区分的路。 | 始对象：∃! 0 → a；Hom(0,a)≅1 |
| 02:25 | 终对象——记作一——对每个对象 a，从 a 到一的箭头存在且唯一。Hom a 一 也是单点集。同一句话，只把箭头的脚和头对调。 | 终对象：∃! a → 1；Hom(a,1)≅1 |
| 02:39 | 在 Hask 里——依惯例忽略底——零就是 Void，一就是单元类型。absurd 见证始对象的出射；const 单元见证终对象的入射。唯一性藏在类型里：没有输入可以区分两条 absurd；终点只有一个值，也区分不了两条 const。 | Hask：Void=0，()=1 |
| 03:01 | 注意：定义里从不打开对象。不问 Void「里面有没有元素」，只问从它出发有几支箭头。这与上一集「对象不可道、箭头可道」完全同调——极端对象，是用箭头计数标出来的。 | 用箭头计数 · 不打开内部 |
| 03:18 | 所以始与终不是两个故事，是同一句模板的两个朝向。下一节，把「朝向」写成对偶范畴。 | 过渡到对偶范畴 |

## 三 · 对偶范畴　`03:29–04:39`

| 时间 | 旁白 | 画面 / 代码 |
|---|---|---|
| 03:30 | 对偶范畴 C 的 op：对象原样不动，每一支箭头掉头——原来从 a 到 b，现在从 b 到 a；复合的顺序跟着反。整张图翻个面，公理一个字都不用改。 | Cᵒᵖ：对象同，箭头反向 |

## 四 · 积与余积　`04:39–06:05`

参考：CTFP 1.5 Products and Coproducts；1.6 Simple Algebraic Data Types；DaoFP ch.1

| 时间 | 旁白 | 画面 / 代码 |
|---|---|---|
| 04:39 | 镜子一照，运算也成对出现。积：给定 a 与 b，找一个对象 a 乘 b，带着两支投影，使得任何一对箭头都唯一地媒介出来。余积——和——把投影换成注入，箭头方向全部反过来。 | 积 ↔ 余积：投影 ↔ 注入 |
| 04:58 | 在 Hask 里，积是配对，余积是 Either。一对值同时持有两边；Either 是「左边或者右边」。同一套普遍性质，只差箭头朝向。 | (a,b) ↔ Either a b |
| 05:12 | 始对象与终对象，正是这两种运算的单位。Void 是和的单位：Either Void a 同构于 a——空的那一支永远用不上。单元类型是积的单位：跟谁配对，都不增加信息。 | Either Void a ≅ a；((), a) ≅ a |
| 05:29 | 所以有无相生，不只是两个极端对象的绰号。零与一，立在类型代数的两端；加与乘——余积与积——从这根标尺长出来。入门第二集点到单位律；本集把它嵌回对偶与普遍性质。 | 0/1 为类型代数标尺 |
| 05:47 | 再进一步：积是终对象式的想法——用「入射的配对」来刻画；余积是始对象式的想法——用「出射的分支」来刻画。学会这一对，后面极限与余极限只是把「一对」换成「一大家族」。 | 极限/余极限预告 |

参考：DaoFP ch.1 Elements；CTFP 1.5 / 1.6

| 时间 | 旁白 | 画面 / 代码 |
|---|---|---|
| 06:06 | 有，还是探针。从单元类型射向 a 的每一支箭头，都挑出 a 的一个全局元素。写成类型：单元箭头 a。元素这个词，上一集说不在范畴词典里——它借终对象重新进场，而且只作为箭头出现。 | () → a 即全局元素 |
| 06:27 | 没有任何箭头从有射向无——Hom 一 零 是空集——所以 Void 没有全局元素。这与「Void 零个值」是同一句话的箭头说法。 | Hom(1,0)=∅ |
| 06:41 | 反过来，一个以 Void 为终点的函数，等于宣告它的定义域「不可能有元素」。构造逻辑里，这正是否定：Not a，等于 a 箭头 Void。 | type Not a = a → Void |
| 06:54 | 于是阴阳又咬合一次：有用来指认「有什么」；无用来陈述「不可能」。探针与否定，是终对象与始对象在逻辑侧的投影。 | 有=指认 · 无=不可能 |

屏幕代码 `s_wu`（`haskell/src/YouWu.hs`）：

```haskell
-- 无：始对象到任意 a 的唯一出射（Hom(0, a) 恰一元）
wu :: Void -> a
wu = absurd
```

屏幕代码 `s_you`（`haskell/src/YouWu.hs`）：

```haskell
-- 有：任意 a 到终对象的唯一入射（Hom(a, 1) 恰一元）
you :: a -> ()
you = const ()
```

屏幕代码 `s_units`（`haskell/src/YouWu.hs`）：

```haskell
-- 无是余积（和）的单位；有是积的单位——又一对付偶
sumUnit :: Either Void a -> a
sumUnit = either absurd id

prodUnit :: ((), a) -> a
prodUnit = snd
```

屏幕代码 `s_probe`（`haskell/src/YouWu.hs`）：

```haskell
-- 有是探针：() -> a 即 a 的全局元素；通往无即否定
element :: a -> (() -> a)
element = const

type Not a = a -> Void
```

屏幕代码 `s_demo`（`haskell/src/YouWu.hs`）：

```haskell
-- 演示：探针挑出元素；否定无法从非空类型构造
demoElement :: Int
demoElement = element (42 :: Int) ()

-- 若有 Not Bool，则对 True / False 都能交出 Void——在忽略 ⊥ 时不存在
demoNot :: Not Void
demoNot = id          -- 唯一「成立」的否定：无否定自身
```
